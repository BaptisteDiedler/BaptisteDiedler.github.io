1. Pourquoi les automates ?

Avant toute définition, un problème concret : on vous donne une longue liste de mots et on demande lesquels contiennent un nombre pair de a, lesquels représentent une adresse IP valide, lesquels sont des identifiants corrects en Python. Impossible de mémoriser tous les « bons » mots : il y en a une infinité.

L'idée centrale de ce cours est que l'on n'a pas besoin de mémoire infinie pour résoudre ces problèmes : un nombre fini d'états de mémoire suffit, car tout ce qui compte du passé se résume à « dans quelle situation intermédiaire je me trouve ». C'est exactement ce que fait un automate à états finis : une machine dotée d'un nombre fini d'états, qui lit un mot lettre par lettre et se déplace d'état en état.

Ces objets sont au cœur des compilateurs (analyse lexicale), des expressions régulières (grep, Python, JavaScript), de la vérification de modèles (model checking) et du contrôle matériel (circuits séquentiels).

« L'automate fini est le modèle de calcul le plus simple qui soit intéressant : il ne peut pas tout calculer, mais ce qu'il calcule, il le calcule exactement, et l'on peut décider de presque tout à son sujet. » — librement inspiré de M. Sipser, Introduction to the Theory of Computation

2. Mots et langages : le socle

2.1 Définitions

Définition (Alphabet). Un alphabet est un ensemble fini de symboles, noté Σ. Exemples : Σ = {a, b}, Σ = {0, 1}.
Définition (Mot). Un mot sur Σ est une suite finie de symboles de Σ. On note ε le mot vide (longueur 0). L'ensemble de tous les mots est Σ*, l'étoile de Kleene : pour Σ = {a, b}, Σ* = {ε, a, b, aa, ab, ba, bb, aaa, …}.
Définition (Concaténation). La concaténation de u = a₁…aₙ et v = b₁…bₘ est uv = a₁…aₙb₁…bₘ. Loi associative d'élément neutre ε, mais non commutative : ab ≠ ba.
Définition (Langage). Un langage sur Σ est une partie quelconque de Σ* : L ⊆ Σ*.
⚠ Piège classique n°1. Ne pas confondre ε (un mot de longueur 0) et ∅ (un ensemble sans élément, donc un langage ne contenant aucun mot — même pas le mot vide). On a {ε} ≠ ∅, et ∅* = {ε}.

2.2 Opérations sur les langages

  • Union L₁ ∪ L₂ : les mots dans L₁ ou L₂ ;
  • Intersection L₁ ∩ L₂ ; complément L̅ = Σ* ∖ L ;
  • Concaténation L₁L₂ = { uv | u ∈ L₁, v ∈ L₂ } ;
  • Étoile L* = ⋃n≥0 Ln : toutes les concaténations (y compris zéro) de mots de L.

Exemples. {ab}* = {ε, ab, abab, ababab, …} — attention, abab est dedans mais pas aba. Le langage « nombre pair de a » : { w ∈ {a,b}* | |w|a est pair }.

« Un langage est un ensemble de mots ; une manière de décrire un langage, c'est déjà calculer. » — esprit de l'ouverture de J. Sakarovitch, Éléments de théorie des automates (2003) : la théorie des automates est née du besoin de représenter des ensembles infinis de façon finie.

3. Automates déterministes (DFA)

3.1 Définition

Définition (Automate fini déterministe). Un DFA est un quintuplet 𝒜 = (Q, Σ, δ, q₀, F) où :
  • Q : ensemble fini d'états ;
  • Σ : alphabet d'entrée ;
  • δ : Q × Σ → Q : fonction de transition totale (de chaque état, pour chaque lettre, exactement une flèche sortante) ;
  • q₀ ∈ Q : état initial ;
  • F ⊆ Q : états acceptants.

Déterministe signifie : même configuration, même comportement — aucun choix, l'exécution d'un mot est une trajectoire unique.

On étend δ aux mots par récurrence : δ̂(q, ε) = q et δ̂(q, ua) = δ(δ̂(q, u), a). Le mot w est accepté si δ̂(q₀, w) ∈ F, et le langage reconnu est L(𝒜) = { w ∈ Σ* | δ̂(q₀, w) ∈ F }.

3.2 Premier exemple complet : nombre pair de a

Ce qu'il faut retenir du passé est uniquement la parité du nombre de a déjà lus : deux situations suffisent !

Table de transition de 𝒜₁ (qpair est l'état initial et acceptant).
étatab
→ ((q_pair))q_impairq_pair
q_impairq_pairq_impair

Lecture de abba : qpair —a→ qimpair —b→ qimpair —b→ qimpair —a→ qpair ✔ (4 lettres a, nombre pair). Que w est accepté si et seulement si |w|a est pair se prouve par induction sur |w| (exercice 5).

3.3 Autres exemples

  • Identifiants Java : une lettre puis des lettres/chiffres — q₀ —lettre→ q₁, q₁ boucle sur lettres et chiffres, F = {q₁}.
  • Divisibilité par 3 en binaire : états q₀, q₁, q₂ = reste modulo 3 du nombre lu ; en lisant un bit b, le reste devient (2r + b) mod 3. Exemple : 1010₂ = 10, divisible par 3 → accepté. Un grand classique d'examen.

3.4 Langages reconnaissables et fermetures

Définition. Un langage L est reconnaissable (ou rationnel) s'il existe un DFA 𝒜 avec L = L(𝒜).
Théorème (fermetures effectives). Les langages reconnaissables sont fermés pour l'union, le complément, l'intersection, la concaténation et l'étoile — et toutes ces fermetures sont effectives (on peut construire l'automate du résultat).

Idées des preuves : union/intersection par produit cartésien (on avance dans les deux automates simultanément, condition d'acceptation adaptée) ; complément en échangeant F et Q ∖ F — c'est ici qu'on voit la puissance du déterminisme : pour un NFA, cette opération immédiate est impossible sans déterminiser (§4).

4. Automates non déterministes (NFA)

4.1 Deux relaxations

Définition (NFA). Un automate non déterministe autorise : (1) plusieurs transitions portant la même lettre depuis un état, voire zéro — δ : Q × Σ → 𝒫(Q) ; (2) dans la variante NFA-ε, des transitions spontanées ε, empruntées sans consommer de lettre. Un mot est accepté s'il existe au moins un chemin étiqueté par ce mot, de q₀ à un état de F.

Le non-déterminisme est un « devin » : on peut se figurer la machine explorant tous les chemins à la fois et acceptant si l'un d'eux gagne.

Exemple — mots se terminant par ab. Pour un DFA, la construction est acrobatique ; pour un NFA, c'est immédiat : à chaque a lu, l'automate peut « parier » que c'est l'avant-dernière lettre. Si le pari s'avère faux, le chemin meurt — ce n'est pas grave : il suffit qu'un chemin gagne.

Le non-déterminisme n'apporte aucune puissance (théorème ci-dessous), mais une concision remarquable : il existe des langages dont le plus petit NFA a n états et le plus petit DFA 2ⁿ états (« la n-ième lettre avant la fin est un a »).

4.2 Le théorème central : déterminisation

Théorème (déterminisation, Rabin & Scott 1959). Pour tout NFA 𝒜, il existe un DFA 𝒜′ avec L(𝒜) = L(𝒜′), donné par la construction par parties (subset construction) : après avoir lu u, le DFA simule l'ensemble des états où le NFA pourrait se trouver. δ′(S, a) = ⋃q ∈ S δ(q, a) ; les états acceptants sont les S qui rencontrent F.

Exemple (déterminisation du NFA ci-dessus). Seules trois parties sont accessibles (toujours élaguer !) :

DFA déterminisé : S₁ est acceptant (contient q₂). L'ensemble ∅ et les autres parties ne sont jamais atteints.
partieab
→ S₀ = {q₀}S₁ = {q₀, q₁}S₀

« Le non-déterminisme est une aide à la spécification, pas une extension du pouvoir de calcul : tout ce qu'un devin devine en un coup, une machine systématique obtient en explorant tout. » — paraphrase de la présentation des NFA dans M. Sipser, Introduction to the Theory of Computation (2012)

5. Expressions régulières et théorème de Kleene

5.1 Définition

Définition (expression régulière). Sur Σ : ∅ et ε sont régulières, ainsi que chaque a ∈ Σ ; si E₁, E₂ sont régulières, alors E₁ + E₂ (union), E₁·E₂ (concaténation) et E₁* (étoile) le sont. Priorités : * > · > +. Chaque expression dénote un langage ⟦E⟧.

Exemples.

  • a(ba)* : {a, aba, ababa, …}
  • (a+b)*a(a+b)* : les mots contenant au moins un a ;
  • (0+1)*11(0+1)* : les chaînes binaires contenant « 11 » ;
  • a*b* : un bloc de a puis un bloc de b.

5.2 Le théorème de Kleene

Théorème (Kleene, 1956). Un langage sur Σ est reconnaissable par automate fini si et seulement si il est dénoté par une expression régulière : Rec(Σ*) = Rat(Σ*).
  • (⇐) des expressions vers les automates : fermetures effectives du §3.4 (constructions de Thompson, McNaughton-Yamada) ;
  • (⇒) des automates vers les expressions : algorithme de McNaughton-Yamada, résolution d'équations de langages, ou élimination d'états.

Ce résultat unifie trois visions — machine (automate), formule (expression), logique — et fonde l'analyse lexicale des compilateurs et les moteurs d'expressions régulières (grep, sed, Lex/Flex).

Kleene introduit ses « événements réguliers » comme les ensembles de comportements qu'une machine à états finis peut distinguer — l'adjectif regular vient de la régularité de ces comportements, descriptibles par un nombre fini de règles. — S. C. Kleene, « Representation of events in nerve nets and finite automata », Automata Studies, 1956
⚠ Regex de Kleene ≠ regex des programmeurs. Les regex de Perl, Python (re… avec backreferences comme (.+)\1) ou look-ahead dépassent strictement le pouvoir des automates finis (l'appariement devient NP-complet). Une regex avec backreference n'est pas un langage rationnel. Les moteurs à sémantique purement régulière (RE2) implémentent exactement la déterminisation du §4.2.

6. Minimisation et lemme de l'étoile

6.1 Myhill-Nerode et minimalité

Théorème (Myhill-Nerode, 1958). Tout langage reconnaissable L possède un unique DFA minimal (à isomorphisme près, et accessible). Ses états sont les classes de l'équivalence de Nerode : u ∼L v si et seulement si ∀z ∈ Σ*, uz ∈ L ⇔ vz ∈ L. Les états du minimal sont exactement les « significations » distinctes que le passé peut avoir pour le futur.

Algorithme de Moore (raffinement de partition) : partir de {F, Q ∖ F} et séparer deux états si une lettre les envoie dans des blocs distincts ; répéter jusqu'à stabilité. Complexité O(n²), améliorée en O(n log n) par Hopcroft (1971).

6.2 Le lemme de l'étoile (pumping lemma)

Lemme (itération). Si L est reconnaissable, il existe p ≥ 1 (prendre p = |Q|) tel que tout w ∈ L avec |w| ≥ p se décompose w = uxy avec |x| ≥ 1, |ux| ≤ p, et u xn y ∈ L pour tout n ≥ 0. Intuition : un chemin acceptant de longueur ≥ |Q| repasse forcément par un même état (principe des tiroirs), et la boucle peut être parcourue 0, 1, 2… fois.
⚠ Piège classique n°2. Le lemme est une implication à un seul sens : il ne sert qu'à prouver qu'un langage n'est pas reconnaissable (par contraposée). Un langage vérifiant le lemme n'est pas nécessairement rationnel (exercice 8).

Exemple — anbn n'est pas rationnel. Prenons w = apbp. Toute décomposition w = uxy avec |ux| ≤ p a x = ak (k ≥ 1). Alors u x² y = ap+kbp ∉ L : contradiction. Il faudra un automate à pile (chapitre suivant). Autres langages standard non rationnels : les palindromes, {a2ⁿ}, {ww | w ∈ Σ*}.

« Le lemme de l'étoile est le premier résultat où l'élève voit la puissance d'une preuve d'impossibilité : une machine à nombre fini d'états ne peut pas compter sans borne. » La forme moderne du critère est le théorème de Myhill-Nerode, qui donne une condition nécessaire et suffisante. — esprit de Hopcroft, Motwani & Ullman, Introduction to Automata Theory, Languages, and Computation (2007)

7. Exercices

Application

Exercice 1 (tracer). Soit le DFA sur Σ = {0,1}, Q = {A, B, C, D}, q₀ = A, F = {D} :
état01
→ ABA
BCA
CDA
((D))DD
a) Tracer le diagramme. b) Le mot 0101 est-il accepté ? c) Deviner le langage. d) Prouver la conjecture par induction.
Solution

b) A —0→ B —1→ A —0→ B —1→ A : rejeté. c) Les mots contenant le facteur 000 (vérifions : 000 donne A → B → C → D ✔, et D absorbe tout). d) Montrer par induction : l'état après u est D ssi u contient 000 ; sinon B si u finit par exactement un 0, C si exactement deux 0 finaux, A sinon.

Exercice 2 (construire). Donner des DFA minimaux pour : a) les mots de {a,b}* contenant au moins un a ; b) les mots de longueur multiple de 3 ; c) les écritures binaires des multiples de 4 ; d) les mots où chaque a est immédiatement suivi d'un b.
Indications

a) 2 états. b) 3 états (compteur modulo). c) 4 états : les deux derniers bits forment 00. d) 3 états — attention au suffixe a en fin de mot (état « fautif » non acceptant, puits).

Exercice 3 (déterminiser). Déterminiser le NFA : q₀ boucle sur a et b, q₀ —a→ q₁, q₁ —b→ q₂, q₂ boucle sur b, F = {q₂}. Quel est le langage reconnu ? Combien d'états après élagage ?
Solution

Une fois q₂ atteint, on ne peut plus lire que des b : tout a tue le chemin. Le langage est celui des mots dont le dernier a est suivi d'au moins un b, décrit par la régulière (a+b)*abb*. Parties accessibles : {q₀}, {q₀,q₁}, {q₀,q₂} — 3 états utiles ({q₂} seul n'est jamais atteint) ; seul {q₀,q₂} est acceptant.

Exercice 4 (expressions régulières). Écrire des expressions régulières pour : a) les mots de {a,b}* de longueur paire ; b) les mots sans deux a consécutifs ; c) les écritures binaires des nombres pairs non nuls ; d) les mots contenant exactement deux b.
Réponses (possibles)

a) ((a+b)(a+b))*   b) b*(ab⁺)*ab* (variantes possibles)   c) 1(0+1)*0   d) a*ba*ba*.

Exercice 5 (preuve par induction). Prouver rigoureusement que le DFA 𝒜₁ du §3.2 reconnaît exactement les mots à nombre pair de a. (Indication : formuler la propriété P(u) : « l'état atteint après u est qpair ssi |u|a est pair », puis faire une induction structurelle sur u, avec les deux cas u = va et u = vb.)
Exercice 6 (minimisation). Minimiser le DFA de l'exercice 1 par l'algorithme de Moore. Est-il déjà minimal ? Justifier avec Myhill-Nerode.
Solution

Oui : les 4 états forment 4 classes de Nerode distinctes, distinguées par les suffixes z ∈ {00, 0, ε} — depuis C, lire 00 mène à l'acceptation ; depuis B, lire 0 ; depuis D, ε suffit ; A n'accepte aucun de ces trois.

Réflexion

Exercice 7 (pumping). Prouver que L = { aⁱbʲ | i > j } n'est pas rationnel. (Choisir w = ap+1bp et discuter les positions possibles du facteur pompé.)
Exercice 8 (piège du lemme). Soit L = { ucv | u, v ∈ {a,b}* } (les mots contenant exactement un c). Montrer que L vérifie le pumping lemma (p = 2, pompage dans la partie avant le c)… mais qu'il est rationnel ! Construire son DFA. Puis expliquer pourquoi le lemme ne peut jamais prouver qu'un langage est rationnel, et montrer sur cet exemple pourquoi son usage réciproque est invalide.
Exercice 9 (Myhill-Nerode appliqué). Prouver avec l'équivalence de Nerode que {anbn} n'est pas rationnel : montrer que les ai, i ∈ ℕ, sont deux à deux non équivalents (distingués par z = bi), donc une infinité de classes — or un DFA a un nombre fini d'états.
Exercice 10 (bornes de concision). Soit Ln = les mots sur {a,b} dont la n-ième lettre avant la fin est un a. Construire un NFA à n+1 états pour Ln, puis montrer que tout DFA pour Ln a au moins 2n états. (Indication : les parties de {1,…,n} sont deux à deux distinguables.)
Exercice 11 (programmation). Implémenter en Python : (a) la lecture d'un DFA depuis un dictionnaire, (b) accepte(A, w), (c) la construction par parties, (d) la minimisation de Moore. Tester sur les exercices 1 à 3. 
# Squelette
def accepte(A, w):
    q = A["q0"]
    for a in w:
        q = A["delta"][(q, a)]
    return q in A["F"]
